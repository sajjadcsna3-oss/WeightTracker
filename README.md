# WeightTracker

A native macOS weight and nutrition tracking application built with SwiftUI, SwiftData, Vision, Core ML, and Swift Charts.

The Meal Lens feature supports on-device food image classification, editable ingredient and portion estimates, nutrition totals, meal persistence, and a diary with calorie charts.

## Requirements

- macOS 14 or later
- Xcode 16 or later

Open `WeightTracker.xcodeproj` in Xcode to build and run the app.
